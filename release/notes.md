CTE2 강화 소모품 제작·구매 방식 조정 · 게임 수정본 0.2.4

- 강화 소모품은 기존 암석·채광·품목별 제작 재료를 사용하는 제작법으로 되돌렸습니다. 레드스톤·청금석·다이아몬드·네더라이트 파편 등 기존 재료를 다시 사용합니다.
- 농사·낚시·목축 재료로 직접 바꾸어 제작하던 네 전문기술 대체 제작법을 제거했습니다.
- 동전 구매는 CTE 동전만 소모합니다. 수확·오벨리스크·봉인 괴물 교환 조각 요구와 신규 지급을 폐지했습니다.
- 동전 구매가는 이전의 8배로 조정했습니다. 청동화 환산 일반/고급/희귀/영웅/전설/신화 256/512/1024/2048/4096/8192입니다. 운영 초기값으로 설정 파일에서 조정할 수 있습니다.
- 전문기술 재료 판매, 직업별 매입가, 재료 3:1 교환과 지갑 1:10 환산은 유지합니다.
- 새 게임 수정본이므로 서버와 참가자 모두 업데이트해야 합니다. 패치기는 기존 1.1.0을 그대로 사용할 수 있습니다.

기본 CTE2와 다른 누적 변경사항과 설치 안내는 README 첫머리에 있습니다.
