CTE2 지도 시련 귀환·전투·위험 표시 개선 · 게임 수정본 0.4.1

- 원본 귀환진주로 전용 전장에서 포기·귀환할 수 있습니다. 보조 손과 바닥 우클릭도 지원합니다. 성공한 뒤에만 한 개를 소모합니다.
- 귀환 이동이 거부되면 저장 위치와 진주를 보존하고 다시 시도할 수 있습니다. /cte endgame leave 는 운영자 권한 없이 사용합니다. 파티 귀환 시 파티 도전 전체가 종료됩니다.
- 현재 전장·구역·남은 적·귀환 방법을 화면 상단에 표시합니다. 구역 전멸 후 목표 발판의 방향과 거리를 안내합니다. CTE 상점에는 전장 안에서 도전·귀환 버튼을 표시합니다.
- 지도 시련은 구역마다 일반 몬스터 30마리가 한 번에 등장합니다. 세 구역 총 90마리와 마지막 보스 1마리입니다.
- 3초 뒤 폭발하는 반경 3.5칸을 붉은 바닥으로 표시합니다. 파티클 설정에 의존하지 않으며, 폭발·구역 완료·도전 종료 시 원래 바닥을 복구합니다.
- 규칙 검사 98개·격리 Forge 검사 725개와 기존 회귀 검사를 통과했습니다. 실제 클라이언트 화면 조작과 30명 부하 시험은 별도로 필요합니다.
