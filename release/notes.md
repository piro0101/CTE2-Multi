CTE2 플레이어 패치 · 패치기 1.1.0

- 패치기에서 운영자용 선택 항목을 제거했습니다. 기존 서버의 업데이트·복구 자료는 유지합니다.
- 폴더 선택창을 주소창과 검색창이 있는 탐색기 형태로 바꿨습니다. Alt+D로 주소창을 선택한 뒤 %appdata%를 입력할 수 있습니다.
- 스텝업/CTE2 호환 수정, 자동 질주, 한글 입력, 밝기 조절을 필수 패치에 포함합니다. 자동 낚시는 제외했습니다.
- 같은 파일 이름·버전이라도 내용이 다르면 원본을 백업하고 수정본으로 교체합니다. 실행 중인 게임이 파일을 사용하는 경우에만 종료 후 재시도하도록 중단합니다.
- README 첫머리에 기본 CTE2와 다른 누적 변경사항을 정리했습니다.
- 게임 수정 모드 자체는 patch-2 / 0.2.3과 동일합니다. 기존 서버의 게임 호환 버전을 유지합니다.

이번에는 패치기 자체가 변경되어 CTE2-Patcher.exe 1.1.0을 다시 내려받아 교체해야 합니다.
