# CTE2 한국어 멀티서버 패치

## 기본 CTE2와 달라진 점

**Craft to Exile 2 2.1.4를 바탕으로 한국어 서버용 상점·경제·강화·제작·육성 편의를 추가한 수정판입니다.** 아래는 최근 한 번의 수정 내역이 아니라 현재까지 누적 적용된 주요 변경사항입니다. 가격과 배율은 운영 중 조정될 수 있습니다.

## 처음 설치하기

1. GDLauncher 등 사용 중인 런처에서 **Craft to Exile 2 2.1.4**를 설치합니다. Minecraft 1.20.1, Forge 47.4.23 기준입니다. [원본 모드팩](https://www.curseforge.com/minecraft/modpacks/craft-to-exile-2/files/8853074)
2. 게임을 완전히 종료하고 위의 **CTE2-Patcher.exe**를 내려받아 실행합니다. 패치기 1.0.0을 사용했다면 이번에 **1.1.0 실행 파일을 다시 받아 교체**하세요.
3. **폴더 선택**을 누릅니다. 사진의 파일 열기 창과 같은 탐색기 형태로 열리며, **Alt+D → `%appdata%` 입력 → Enter**로 AppData의 Roaming 폴더에 갈 수 있습니다. 오른쪽 검색창도 사용할 수 있습니다.
4. GDLauncher라면 주소창에 `%appdata%\gdlauncher_carbon\data\instances`를 입력한 뒤 자신의 CTE2 폴더 안 **instance**를 선택합니다. `mods`, `config`, `resourcepacks`가 보이는 폴더입니다. 패치기 본문의 경로 칸에 `%appdata%`가 포함된 전체 경로를 직접 붙여 넣어도 됩니다.
5. **런처 선택**에서 GDLauncher 등 현재 쓰는 런처 실행 파일을 지정합니다.
6. **업데이트 후 런처 실행**을 누릅니다. 플레이어용 필수 패치만 제공하며 별도의 패치 종류 선택은 없습니다. 한국어·한글 리소스팩 자동 설정은 기본으로 켜져 있습니다.
7. 열린 런처에서 해당 CTE2 인스턴스를 실행하고 안내받은 서버로 접속합니다.

로그인과 마인크래프트 실행은 현재 사용 중인 런처가 담당합니다. 패치기는 Microsoft 계정 비밀번호를 요청하거나 저장하지 않습니다. 원본 모드팩 전체를 내려받는 기능은 포함하지 않습니다.

## 기존 파일도 수정본으로 교체하나요?

**네. 파일 이름이나 모드 버전 표시가 같아도 내용이 다르면 교체합니다.** 패치기는 관리 대상 파일의 크기와 SHA-256을 비교하고, 배포본과 다르면 기존 파일을 백업한 뒤 검증된 수정본으로 교체합니다. 이미 수정본과 완전히 같은 파일은 다시 쓰지 않습니다.

**“사용 중이면 중단”은 마인크래프트가 실행 중이라 모드 JAR·리소스팩을 읽고 있는 경우를 뜻합니다.** 기존 파일이 설치되어 있다는 이유로 업데이트를 생략하는 것이 아닙니다. 게임을 켠 채 교체하면 실행 중인 코드와 파일이 어긋날 수 있으므로, 완전히 종료한 뒤 다시 업데이트하세요.

- 공식 GitHub 배포본의 목록·크기·내용 해시를 검사한 뒤 적용합니다.
- 변경 전 파일은 게임 폴더의 `.cte2-patcher/backups`에 보관합니다.
- 관리하는 추가 모드의 구버전 파일은 백업 보관 후 비활성화해 중복 로딩을 막습니다.
- 적용 실패 시 백업을 복구하고, 강제 종료로 남은 미완료 기록도 다음 실행에서 확인합니다.
- 월드·캐릭터·저장한 서버 목록을 패치하지 않습니다. 한국어 자동 설정은 기존 키 설정과 그 밖의 옵션을 보존합니다.

## 이후 업데이트

게임을 종료하고 같은 패치기의 **업데이트 후 런처 실행**을 누르면 최신 배포본을 확인하고 설치합니다. 인터넷 연결이나 파일 검증에 실패하면 이 버튼으로 런처를 실행하지 않습니다. 패치기 자체의 새 버전이 필요하면 최신 실행 파일을 받으라는 안내가 나옵니다.

서버와 플레이어의 **게임 수정본 호환 버전**이 일치해야 접속할 수 있습니다. 이번처럼 패치기 화면만 바꾸는 경우에는 게임 수정본의 호환 버전을 유지합니다. 실행 전 파일 검사는 의도적인 모드 변조를 탐지하는 보안 프로그램은 아닙니다.

## 패치 유지 관리

참가자용 배포 대상은 `release/payload/client`이며 패치기에는 운영자용 선택 항목이 없습니다. 기존 서버의 업데이트·복구 경로를 보존하기 위해 서버 배포 원본과 별도 서버 ZIP은 유지합니다. 게임 폴더 전체, `saves`, `servers.dat`, 로그·백업·계정 파일을 올리지 마세요.

1. 수정 모드와 설정을 검증한 뒤 배포 대상에 반영합니다. 필수 편의 모드도 같은 절차로 관리합니다.
2. 게임 코드가 바뀌면 `release/game-version.json`의 원본 JAR 해시와 새 게임 호환 ID를 함께 갱신합니다. 패치기·문서만 바뀌면 게임 호환 ID를 유지합니다.
3. `release/notes.md`에 이번 변경을 적고 `main`에 반영합니다.
4. **Actions → Build and publish CTE2 patch**가 빌드·백업/복구·전체 설치 시험을 통과하면 새 Release를 게시합니다. 참가자 다운로드 주소는 최신 배포를 가리킵니다.
5. 게임 내용이 바뀐 경우 서버에도 동일한 게임 수정본을 별도로 적용해야 합니다. 공개 플레이어용 패치기로 서버를 수정하지 않습니다.

## 검증 범위

패치기 경로/압축 검사, 손상 다운로드 거부, 같은 이름·같은 크기여도 내용이 다른 파일 교체와 원본 백업, 사용 중인 파일 보호, 설치 확인, 한글 설정 보존, 실패 복구, 미완료 기록 복구를 자동 시험합니다. 탐색기 폴더 선택창에서 `%appdata%` 경로 이동과 선택 결과 반영도 확인했습니다. 실제 Minecraft 30명 접속·새 PC에서 처음 설치·운영 서버 부하 검증은 별도로 남아 있습니다.
