# CTE2 서버 패치

한국어 CTE2 서버 참가자를 위한 자동 업데이트 패치기입니다.

**[패치기 다운로드](https://github.com/piro0101/CTE2-Multi/releases/latest/download/CTE2-Patcher.exe)** · [최신 변경사항](https://github.com/piro0101/CTE2-Multi/releases/latest)

## 처음 설치하는 참가자

1. GDLauncher 등 사용 중인 런처에서 **Craft to Exile 2 2.1.4**를 설치합니다. Minecraft 1.20.1, Forge 47.4.23 기준입니다. [원본 모드팩](https://www.curseforge.com/minecraft/modpacks/craft-to-exile-2/files/8853074)
2. 게임을 완전히 종료하고 위의 **CTE2-Patcher.exe**를 내려받아 실행합니다.
3. **폴더 선택**에서 CTE2의 실제 게임 폴더를 고릅니다. `mods`, `config`, `resourcepacks` 폴더가 보이는 위치입니다. GDLauncher 인스턴스 바깥 폴더를 선택하면 내부 `instance`를 찾아 줍니다.
4. **런처 선택**에서 GDLauncher 등 현재 쓰는 런처의 실행 파일을 지정합니다.
5. **플레이어용 필수 패치**를 선택하고 **업데이트 후 런처 실행**을 누릅니다. 한국어 및 한글 리소스팩 자동 설정은 기본으로 켜져 있습니다.
6. 열린 런처에서 해당 CTE2 인스턴스를 실행하고 운영자가 안내한 서버 주소로 접속합니다.

로그인과 마인크래프트 실행은 현재 사용 중인 런처가 담당합니다. 패치기는 Microsoft 계정 비밀번호를 요청하거나 저장하지 않습니다. 원본 모드팩 전체를 내려받는 기능은 포함하지 않습니다.

## 이후 업데이트

게임을 종료하고 패치기의 **업데이트 후 런처 실행**을 누르면 최신 배포본을 확인하고 설치합니다. 파일을 직접 찾아 복사할 필요가 없습니다. 인터넷 연결이나 검증에 실패하면 이 버튼으로 런처를 실행하지 않습니다.

서버와 클라이언트는 모드의 통신 버전과 패치 배포 ID를 함께 확인합니다. 서버가 새 패치로 올라가면 구버전은 업데이트해야 접속할 수 있습니다. 패치 파일의 내용도 실행 전에 검사합니다. 이것은 의도적인 모드 변조를 탐지하는 보안 프로그램은 아닙니다.

## 패치기가 하는 일

- 공식 GitHub 배포본의 파일 목록·크기·SHA-256을 확인한 뒤 적용합니다.
- 변경 전 파일을 게임 폴더의 `.cte2-patcher/backups`에 보관합니다.
- 사용 중인 모드·리소스팩을 감지하면 덮어쓰지 않고 중단합니다.
- 적용 중 실패하면 백업을 복구하며, 강제 종료로 남은 미완료 기록도 다음 실행에서 확인합니다.
- 예전 활성화 퀘스트 데이터와 중복된 자체 수정 모드는 백업 보관 후 비활성화합니다.
- 월드 데이터·캐릭터·저장한 서버 목록은 패치 묶음에 포함하지 않습니다. 선택한 한글 자동 설정은 기존 키 설정 등을 보존하고 언어/리소스팩 항목만 수정합니다.

선택 편의 모드는 이 필수 패치에 자동으로 추가하지 않습니다. 서버 운영 정책에 따라 별도로 안내합니다.

## 운영자

1. 공식 CTE2 2.1.4 서버팩을 준비하고 서버를 완전히 종료합니다.
2. 패치기에서 서버의 `mods`가 보이는 폴더를 고른 뒤 **운영자용 서버 패치 → 확인하고 업데이트**를 누릅니다.
3. 기존 월드는 `defaultconfigs`만 갱신해도 `world/serverconfig`가 자동 변경되지 않습니다. 기존 `mine_and_slash-server.toml`의 `MAP_START_COOLDOWN_SECONDS`를 **10**으로 확인하세요. 새 월드는 포함된 기본값 10초를 사용합니다. 기존 월드의 다른 설정은 그대로 유지합니다.
4. 서버를 시작하고 참가자에게 같은 패치로 업데이트하도록 안내합니다.

서버 패치에는 클라이언트 전용 Inspector와 한국어 리소스팩을 넣지 않습니다. 서버 주소·화이트리스트·포트·메모리 할당·정기 백업은 운영 환경에 맞게 별도로 설정합니다.

## 새 패치 발행

이 저장소의 `release/payload/client`와 `release/payload/server`가 배포할 파일입니다. 게임 폴더 전체를 올리지 마세요. 특히 `saves`, `servers.dat`, 개인 설정, 로그, 백업, 계정 파일을 올리면 안 됩니다.

1. 수정 모드를 검증하고 위의 두 폴더에 변경된 배포 파일을 반영합니다. 공통 모드 JAR은 양쪽이 같아야 합니다.
2. `release/notes.md`에 변경사항을 적고 `main`에 반영합니다.
3. **Actions → Build and publish CTE2 patch**가 패치기 시험과 압축 검증을 통과하면 새 GitHub Release를 게시합니다. 수동 발행은 같은 작업의 **Run workflow**로 실행합니다.
4. 매번 새로운 `patch-번호`가 생성되며 클라이언트/서버 모드에 동일한 ID를 넣습니다. 운영자도 서버 패치를 적용해야 새 버전이 필수가 됩니다.
5. 참가자는 같은 패치기를 다시 실행하면 됩니다. 다운로드 주소는 최신 배포를 가리킵니다.

이 README 자체가 인터넷에서 접속할 수 있는 설치 설명서입니다. 다운로드 링크는 첫 Release가 게시된 뒤 작동합니다.

## 검증 범위

패치기 경로/압축 검증, 손상 다운로드 거부, 사용 중인 파일 보호, 파일 설치 확인, 한글 설정 보존, 실패 복구, 미완료 기록 복구를 자동 시험합니다. 모드 회귀 검증도 별도 수행합니다. 실제 Minecraft 30명 접속·새 PC에서 처음 설치·운영 서버 부하 검증은 아직 남아 있습니다.
