상점 NPC · CTE 안내 메뉴

플레이어 이용

인벤토리의 Food Book 아래 아이콘을 누르면 CTE 안내 · 자료실 메뉴가 열립니다.

- 아이템 옵션사전 / 빌드 연구소: 메뉴 위쪽의 큰 바로가기로 브라우저에서 엽니다. Minecraft의 링크 확인 창이 먼저 표시됩니다.

- 내 능력치: 원본 Mine and Slash의 내 캐릭터 능력치 상세 화면을 엽니다.

- NPC 상점 이용 안내: 각 NPC가 제공하는 기능을 확인합니다.

상점은 운영자가 설치한 NPC를 우클릭해 이용합니다. NPC마다 담당 메뉴만 표시하며 검색·종류 필터·가격 정렬·옵션 미리보기와 기존 구매 확인을 이용합니다. 거래할 때는 해당 NPC에서 8블록 안에 있어야 합니다.

기존 /cte shop과 상점 관련 명령어는 요청에 따라 유지합니다. 인벤토리 버튼은 정보·능력치·자료실 메뉴로 연결됩니다.

운영자 설치

1. 운영자(OP) 권한으로 설치하려는 곳에 섭니다.

2. 내 앞 2블록에 NPC가 설 수 있는 공간을 비웁니다. 블록과 기존 NPC를 강제로 이동하지 않습니다.

3. CTE 안내 → 운영자 · 상점 NPC 설치·제거에서 종류를 골라 설치합니다. 결과는 게임 채팅에 표시됩니다.

4. 다음 NPC는 다른 자리에 서서 설치합니다. 같은 위치의 중복 설치를 막습니다.

NPC는 설치 위치에 고정되고 피해·중력·주민 음성을 비활성화합니다. 이름과 주민 복장을 상점별로 구분합니다. NPC는 일반 엔티티 저장 방식으로 월드에 보존되며 청크를 강제로 불러오지 않습니다. 주변 상점 NPC만 식별하므로 일반 주민은 변경하지 않습니다.

명령어로 관리

/cte npc list: 종류별 설치 명령 안내.

/cte npc spawn normal: 일반 유니크 교환상 설치. normal 자리에 표의 종류를 넣습니다.

/cte npc remove normal: 8블록 안의 해당 종류 중 가장 가까운 NPC 1명만 제거. 다른 종류와 일반 주민은 유지합니다.

예: /cte npc spawn orbs, /cte npc spawn maps, /cte npc spawn market, /cte npc spawn pinnacle.

기존 /cte pinnacle spawn·/cte pinnacle remove도 유지합니다. 새 설치 메뉴에서는 종류별로 가까운 1명을 선택 제거합니다. 설치·제거는 서버가 운영자 권한을 다시 검사합니다.

MCA 충돌로 생긴 구버전 상인 정리

서버와 참가자 모두 업데이트·재시작한 뒤, 상인 8블록 안에서 /cte npc remove normal을 반복하여 기존 일반 유니크 상인을 한 명씩 정리하고 /cte npc spawn normal로 다시 설치하세요. 강화 상인은 normal 대신 orbs를 사용합니다. 새 CTE 상인은 원본 주민 외형으로 설치되며 MCA 자동 치환에서 제외합니다. 일반 주민의 MCA 기능은 유지합니다.

구버전 정리는 MCA 주민의 정확한 색상 포함 이름·무적·AI 비활성·영구 유지가 모두 일치할 때만 동작합니다. 이름만 같은 일반 주민은 제거하지 않습니다. 실제 MCA 7.6.26을 포함한 격리 Forge 서버 검사 411개를 통과했습니다.

기존 서버 적용

서버와 모든 참가자가 game-0.6.1으로 업데이트하고 재시작해야 합니다. 패치기에는 모드와 인벤토리 메뉴 설정을 함께 포함합니다. 기존 정점 NPC는 저장된 태그를 인식해 계속 사용하며, 다음 로드·틱에서 표시·무적·고정 설정을 보완합니다. 다른 상점 NPC는 운영자가 원하는 장소에 새로 설치합니다. 기존 월드를 열어 자동으로 일괄 설치하지 않습니다.

가격, 보스 포인트, 재료 수량, 해금 조건, 재료 3:1 교환, 지갑 환산, 유니크 귀속, 강화 정점 조각 드랍·제작법은 변경하지 않습니다. NPC별 메뉴는 기존 상점 거래 처리를 사용합니다. NPC가 삭제되거나 종류가 바뀌거나 멀어지면 기존 NPC 거래 목록으로 결제할 수 없습니다.

검증: 기존 전체 회귀 검사, 원본 능력치 상세 화면 연결, 격리 Forge 검사 411개 통과. 두 합성 서버 계정으로 거래 분리를 확인했습니다. 실제 사람의 인게임 GUI 조작·30명 동시 부하 시험은 별도입니다.
