# 추가 도전 콘텐츠 폐지 안내

2026년 11월 14일, 별도로 추가했던 **초월정점·4인 파티 보스·개인시련·지도 시련 스피드런**을 롤백했습니다.

전용 지도·검은 지도 강화 오브·안내인·입장 메뉴·전투·보상·기록·전장 화면은 더 이상 제공하지 않습니다. **원본 CTE2의 정점·우버·지도·퀘스트·리그는 유지합니다.** 상점·경제·제작·강화·번역·편의 모드 수정도 유지합니다.

서버와 참가자 모두 최신 패치를 적용하고 서버를 재시작하세요. 기존 전장에 남은 캐릭터는 다음 접속 때 저장된 입장 전 위치로 복귀하며, 위치 정보가 없으면 오버월드 생성 지점으로 복귀합니다. 다른 모드가 이동을 막으면 저장 위치를 보존하고 재시도합니다.

옛 도전 아이템은 세이브 누락 오류를 피하기 위한 비활성 아이템으로만 남습니다. 구매·제작·지도 입장·오브 사용은 불가능합니다. 옛 전장 지형과 개인 기록을 오프라인에서 직접 삭제하지 않습니다. 옛 전장의 강제 로딩은 해제하고 해당 도전 안내인·몬스터는 로드 시 제거합니다. 일반 주민과 기존 CTE2 몬스터는 건드리지 않습니다.

`config/cte2_endgame.json`은 최신 배포에서 제외하며 현재 코드에서 읽지 않습니다. 이전 설치에 파일이 남아 있어도 도전 기능을 켤 수 없습니다.
