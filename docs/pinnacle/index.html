강화 정점 지도 · 정점 교환상

입장 방법

1. 기존 CTE2의 정점 해금 조건을 달성하고 미사용 정점 지도를 준비합니다.

2. 정점 보스를 처치해 강화 정점 조각을 얻습니다. 보스당 1개 확정 공용 드랍이며 보스 위치에 떨어집니다. 조각 4개를 모아 일반 작업대 3×3 칸의 네 모서리에 배치하면 강화 오브 1개를 제작합니다. 인벤토리 2×2 칸에서는 제작할 수 없습니다. 보스 포인트 구매는 제거했습니다.

3. 검은색 정점 지도 강화 오브를 집어 미사용 정점 지도 1개에 끌어다 놓습니다. 설치한 지도·일반 지도·우버 지도·이미 강화한 지도에는 사용할 수 없습니다.

4. 툴팁의 강화 표시를 확인하고 기존 지도 장치로 입장합니다. 원래 지형·몬스터·보스 패턴·접사·전리품·귀환진주를 사용합니다.

기본 몬스터 체력은 3배, 공격력은 1.25배입니다. 플레이어·용병·소환수는 강화되지 않습니다. 배율과 보상은 변환 순간 지도에 저장됩니다.

클리어와 정점 주화

원본 지도 완전 클리어 판정 시 현재 해당 지도에 있는 원본 참가자에게 각 10개를 지급합니다. 지도 UUID와 계정마다 한 번 지급합니다. 일반 정점 지도는 이 주화를 주지 않습니다. 주화는 코인지갑에 보관할 수 있으며 기존 CTE 화폐·Lightman 동전과는 별도입니다.

공간이 부족하면 사라지지 않고 계정 미수령 보상에 보관합니다. NPC의 보상 수령에서 한 번에 최대 64개씩 받습니다. 사망하거나 지도 밖에 있는 플레이어는 완료 보상 대상에서 제외됩니다.

정점 교환상

운영자가 스폰에 설치한 NPC를 우클릭합니다. 일반 플레이어는 명령어 권한이 필요 없습니다. NPC 반경 8블록 안에서 이용합니다. 검색·품목 종류·가격 오름차순/내림차순·등급 필터와 구매 확인을 지원합니다.

코덱스는 장비 접두사·접미사처럼 나뉘지 않는 원본 시스템이므로 추가 옵션 한 개만 지정합니다. 착용 조건·나머지 옵션·수치는 원본대로 생성합니다. 주얼은 동시 부착 불가·중복 제한을 지키며, 타락·고유·오라 특수 주얼은 대상이 아닙니다. 선택 화면은 선택한 능력치 종류를 보장하며 최대 수치를 보장하지 않습니다.

특수 유니크는 정점·우버·보물상자·수확·오벨리스크·예언·봉인 괴물 전용입니다. 활성 유니크만 취급하며 숨김·폐기·가중치 0 품목은 제외합니다. 구매품은 계정 귀속·재판매 금지이며 분해할 수 있습니다. 일반 유니크 교환소와 별도의 정점 주화 경로입니다.

운영자 설치와 설정

- /cte pinnacle spawn: 현재 위치에 정점 교환상 설치.

- /cte pinnacle remove: 반경 8블록의 정점 교환상만 제거. 일반 주민에는 적용하지 않습니다.

- config/cte2_pinnacle.json: 한국어 설명과 기본 가격·배율·개별 품목 가격·유니크 포함/제외 설정.

- 수정 뒤 /cte reload. 기존 강화 지도에 저장된 배율·보상에는 소급하지 않습니다.

- 서버와 클라이언트 모두 game-0.5.1 업데이트와 재시작이 필요합니다.

이전 별도 차원의 초월정점·4인 파티 전장·개인시련·스피드런은 폐지 상태를 유지합니다. 이번에는 원본 지도 체계를 사용합니다.

검증: 기존 전체 회귀 검사와 격리된 Forge 서버 249개 검사 통과. 실제 연결된 사람의 GUI 조작·장시간 전투·30명 부하 시험은 아직 별도입니다. 가격과 배율은 초기 운영값입니다.
