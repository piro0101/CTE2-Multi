옵션사전: 원하는 장비 종류를 고른 뒤 능력치 이름으로 검색하세요. 기존 2026-10-31 자료를 공개용으로 제공합니다.

빌드 연구소: 첫 접속 때 계산기를 준비하는 데 잠시 걸릴 수 있습니다. 장비 칸이나 스킬 아이콘을 눌러 시작하세요.

캐릭터 파일: 직접 선택한 파일은 브라우저 안에서 읽습니다. 게임 세이브를 바꾸거나 운영자 서버로 보내지 않습니다.

계산 결과: 직접 피해·속도·자원 흐름을 비교하는 추정 모델입니다. 일부 발동 효과·소환 AI·지속 피해는 재현하지 않으므로 실제 게임 DPS와 함께 확인하세요.
